# Privelle

Private luxury for modern couples.

## Getting Started

This is a premium mobile-first catalogue and lead-generation website built with Next.js 14, React, TypeScript, Tailwind CSS, and Framer Motion.

### Tech Stack

- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **UI Icons**: Lucide React
- **Utilities**: clsx, tailwind-merge

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build

```bash
npm run build
npm start
```

## Project Structure

```
├── app/                    # Next.js App Router
├── components/
│   ├── layout/            # Navbar, Footer, etc.
│   ├── sections/          # Page sections
│   ├── cards/             # Card components
│   ├── motion/            # Animation components
│   └── ui/                # Reusable UI components
├── constants/             # Data constants
├── lib/                   # Utilities (WhatsApp, launch date, etc.)
├── public/
│   └── images/
│       └── placeholders/  # Image placeholders
└── tailwind.config.ts     # Theme configuration
```
